iProbe 后台

用后台密码或管理 token 登录（两者都填密码框）。没设过密码或忘了密码：在服务器执行 sudo iprobe passwd 重设；不知道 token 用 sudo iprobe token 查看。 没有 iprobe 命令就用完整路径 sudo python3 /usr/local/lib/fwprobe/probe.py passwd。 改完立即生效，不用重启服务。
